# Moment Composer writes files through a dev-only Vite middleware

The Moments timeline needs an in-editor compose bar where the author types a short post and clicks "发布" to create a new Moment Markdown file in `src/content/moments/`. The site is a purely static Astro build with no adapter and no server runtime, so the write path is implemented as a Vite plugin (`apply: "serve"`) that registers a `POST /api/moments` middleware on the dev server only, and the compose bar component is server-rendered only when `import.meta.env.PROD` is false. The production bundle therefore contains no compose bar markup and no API route — the endpoint is absent rather than hidden. Alternatives considered: a runtime Astro endpoint (`prerender = false`) would require a server adapter and break the static build; a standalone CLI script would fragment the authoring flow. Both were rejected to keep the site purely static with zero production footprint.
